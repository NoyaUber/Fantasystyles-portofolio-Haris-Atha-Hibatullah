# Fantasy Portfolio — UI Polish

Penyempurnaan visual pada proyek portofolio yang sudah ada. Struktur konten dan fitur utama dipertahankan: halaman utama, profil, Character Status, Quest Journal, proyek, sampul novel favorit, tokoh inspiratif, dan cita-cita.

## Menjalankan
Buka `index.html` melalui browser atau deploy seluruh isi folder ke Vercel.

## Catatan
Sebagian gambar sampul buku dan tokoh diambil dari URL eksternal sehingga membutuhkan koneksi internet. Detail sumber gambar tersedia di `image-credits.txt`.
